Project Overview

ESP32-Based Self-Balancing Robot

Project Objective

Design and develop a two-wheeled self-balancing robot using an ESP32 microcontroller, an MPU6050 inertial measurement unit, and stepper motor control.

Working Principle

The MPU6050 measures the robot’s tilt and angular motion. The ESP32 processes this information and calculates corrective motor commands using a feedback control algorithm.

Control System

* Sensor: MPU6050
* Controller: ESP32
* Control method: Complementary filter and PID
* Motor drivers: A4988
* Actuators: Two NEMA 16 stepper motors

Development Goals

* Real-time tilt measurement
* Closed-loop motor control
* Balance correction
* Wireless control development
* Improved stability and response

Development Status

Hardware integration and control-system development are ongoing.
